# AGENTS.md

The instructions for this repository live in [CLAUDE.md](CLAUDE.md) — read that
file first, whichever agent you are.

It covers what the client is and why it has no runtime dependencies, the layout
and the import rules that keep it acyclic, how commands are assembled (search
grammar is assembled, never appended), and a list of verified Tile38 protocol
quirks that a previous implementation got wrong silently. Contributor-facing
setup and the PR checklist are in [CONTRIBUTING.md](CONTRIBUTING.md).
